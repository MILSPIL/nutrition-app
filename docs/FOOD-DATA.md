# Локальні джерела харчових значень

HERMES-FOOD-01, крок 3. Дані USDA FoodData Central, CC0-1.0. Ліцензія: https://fdc.nal.usda.gov/. Офіційні набори: https://fdc.nal.usda.gov/download-datasets/. Джерела, версії, URL, SHA256 та очікувані кількості заморожені в `server/trainer/food-data-manifest.json`. Автоматичного оновлення або API-виклику під час пошуку немає.

Імпорт: `node scripts/food-data-import.mjs ARCHIVE_DIRECTORY OUTPUT_SQLITE`. У каталозі мають бути три архіви з manifest. Команда відхиляє інший checksum/кількість, наявний output, незавершений `.tmp`; при помилці прибирає лише власний `.tmp`. Вихід відкривається сервісом лише для читання після перевірки SHA256 з release manifest. Архіви та SQLite поза Git; невеликий відкритий excerpt є регресійною фікстурою, не персональними даними.

На 2026-10-24: Foundation 2026-04-30 має 395 позицій, з них 32 `null`; імпортовано 363, 52 неповні. SR Legacy 2018-04: 7793. FNDDS 2024-10-31: 5432, один без харчових значень. Разом 13588, часткових 53. Жоден пропуск не стає нулем.

Mapping: білки1003, жири1004, вуглеводи1005 у грамах; ккал2048 (специфічні коефіцієнти), далі2047 (загальні), далі1008. Значення на100г їстівного продукту. ID1062 у кДж не підставляється як ккал. Statistical min/max не є порогом відсутності значення. Пояснення одиниць та energy: https://fdc.nal.usda.gov/Foundation_Foods_Documentation/.

Ознака приготування виводиться з опису, а не з коефіцієнта сирої/готової маси. Явне кінцеве cooked/prepared має пріоритет над початковим raw/from dried. Roasted,dry гречка залишається сухою. Якщо відповідник не знайдений, модель може запропонувати явну оцінку з припущеннями. Пошук англомовний; українські/російські пошукові ознаки перекладає Hermes. Каталог не доводить склад конкретної домашньої страви або українського бренду.

Результат обмежений п’ятьма записами. Сервер приймає тільки ID, повернений у цьому turn, і копіює числовий snapshot. Модель не може замінити числа чи URL каталогу. Запит відомого бренду до загального каталогу вимагає позначеного аналога; повторний ширший пошук не знімає цю вимогу. Етикетка має бути пов’язана з фото конкретного рядка; фото не потрапляє у збережений snapshot. Для estimate немає вигаданих database ID/URL. Несумісні г/мл, невідома порція або часткові БЖВ лишаються нотаткою без внеску в підсумок.

Перевірки цього блока підтверджують арифметику та походження даних. Точність вибору живого Sonnet, повні H02 і приймання користувачем перевіряються окремо.
