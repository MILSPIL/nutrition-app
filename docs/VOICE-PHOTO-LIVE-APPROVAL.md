Це уточнення кроку 4 [погодженого плану](superpowers/plans/2026-10-20-voice-photo.md), а не новий дозвіл на публікацію. Goal `objective_e45aa8ac1aa3`; G05/G07/G08/G11 лишаються pending.

## Кредити й ключ

Юрій підтвердив «Claude Code / Anthropic». Щомісячні кредити Max 5x $100 або Max 20x $200 діють у прямому Claude API через прив’язану Console organization. Це умови програми, не перевірка особистого залишку. Баланс спільний для організації та не переноситься. [Умови](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans).

За прямим рішенням Юрія лишаємо **Default**, де він створив окремий ключ SciSense. Нову організацію чи workspace не створюємо. Локальний запис `scisense-anthropic / api-key` у macOS Keychain знайдено, значення непорожнє й має очікуваний формат. Читальний `GET /v1/models/claude-sonnet-5-5` повернув 200, точний ID, image_input і structured_outputs. Ключ не друкували; генерацій не було. Область Default відома зі слів Юрія й знімка, а не з Models API.

До витрат потрібно перевірити належну організацію, її залишок/строк кредиту та поведінку після вичерпання кредиту. Окремий ключ дозволяє відрізняти використання, але не створює власний баланс чи workspace-ліміт у спільному Default. Стелю застосунку забезпечує наш постійний бюджет. [Облік використання](https://support.claude.com/en/articles/9534590-cost-and-usage-reporting-in-the-claude-console), [workspaces](https://support.claude.com/en/articles/9796807-create-and-manage-workspaces-in-the-claude-console). OAuth Claude Code не використовується як API key.

## Маршрут і модель

| Варіант | За | Проти |
| --- | --- | --- |
| B. Whisper на Mac + Sonnet 5.5 | Усі зовнішні AI-витрати з Claude-кредитів; звук лишається на Mac | Потрібен локальний аудіоадаптер і модель; Mac працює під час тесту |
| A. OpenAI transcription + Sonnet 5.5 | Аудіоадаптер уже реалізовано; придатний для серверного маршруту | Звук оплачується поза Claude-кредитами; потребує окремого дозволу й ключа |

Рекомендація B зберігає вимогу Юрія використати Claude-кредити. Haiku більше не є моделлю цього прогону. Автоматичної заміни Sonnet іншою моделлю немає. A лишається непогодженою альтернативою, без купівлі балансу.

- Голос: локальний `whisper.cpp v1.9.5 / large-v3-turbo-q5_0`, модель 547 MiB. Прочитано README, models/README і server.cpp у clone commit `d1be6fde11ac6e0407606b4e42fe72d34add8037`. Модель/адаптер ще не встановлені, якість української й швидкість треба перевірити. [Джерело](https://github.com/ggml-org/whisper.cpp/tree/d1be6fde11ac6e0407606b4e42fe72d34add8037).
- Текст і фото: `claude-sonnet-5-5`, $2 за 1 млн вхідних токенів та $10 за 1 млн вихідних. Sonnet приймає текст і зображення. [Модель і тарифи](https://platform.claude.com/docs/en/models/sonnet-5-5/overview).
- Для Sonnet адаптер використовує `output_config.format` з JSON schema, `thinking.type=between_tools`, effort=medium, max_tokens=4096. Відповідь читається за типом блока. Forced tool_choice не передається; refusal, обрізаний JSON, інша модель або відсутні поля не зберігаються як успіх. Непідтримувані grammar-обмеження перенесені в опис, а початкові числові/довжинні межі перевіряються локально. [Міграція Sonnet](https://platform.claude.com/docs/en/models/sonnet-5-5/migration-guide), [JSON outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs).

## Оновлений бюджет B

10 голосових повідомлень до 90 секунд, серед них 5 із двома фото. Це 10 локальних транскрипцій та 20 викликів Sonnet: початковий розбір і повторний розбір після кожного фото. Повтори й невдачі не повертають резерв і не повторюються автоматично.

| Тип виклику | Кількість | Резерв одного | Разом |
| --- | ---: | ---: | ---: |
| Локальна транскрипція | 10 | $0 API | $0 API |
| Текст, без фото | 10 | $0.136960 | $1.369600 |
| Одне фото | 5 | $0.156960 | $0.784800 |
| Два фото | 5 | $0.176960 | $0.884800 |
| Усі виклики Sonnet | 20 | | **$3.039200** |

Калькуляція чинного `reservation()` використовує до 32000 UTF-8 байтів тексту, 16000 токенів запасу інструкцій/схеми, 10000 на фото та 4096 токенів відповіді. Це консервативний резерв, не прогноз фактичного рахунку. Ліміт **$5 на весь прогін**, тільки з Claude-кредитів, запропонований замість попередніх $0.25 для Haiku. Поповнення балансу не входить у запит. Перед першим платним викликом ще раз перевірити тарифи й доступність моделі.

Бюджет SQLite не скидається при перезапуску або зміні дня. Пошкодження чи втрата файла означає зупинку до звірки витрат. Чинні обмеження: 6 викликів за ковзну хвилину, 30 за UTC-добу, 2 одночасні на UID. Для B потрібно окремо під’єднати локальний STT до квот без OpenAI-резерву; це ще не активовано. Нова стеля або новий прогін потребують нового дозволу. Інші ключі в Default можуть витратити спільні кредити, тому їхній залишок перевіряємо до запуску.

У сценаріях 6–10 спершу фото назви, потім таблиці. Першу відповідь після назви не видаємо за точну етикетку. Збереження позитивних сценаріїв: одна «Додати», перевірка правильного дня та повторне читання після reload, без дублів. 8 і 10 очікувано зупиняються на уточненні. Ця перевірка API не підміняє 7-денний G09-пілот і його знаменник усіх спроб.

Anthropic API: стандартне видалення input/output протягом 30 днів, з винятками політики/закону; без навчання на цих даних за замовчуванням. Files API і добровільне передавання для навчання не використовуємо. [Зберігання](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data), [навчання](https://privacy.claude.com/en/articles/7996868-is-my-data-used-for-model-training).

Для конкретного OpenAI `/v1/audio/transcriptions` таблиця документації вказує відсутність зберігання в abuse monitoring/application state і відсутність навчання. Це не переноситься автоматично на інші OpenAI endpoints. [Політика endpoint](https://developers.openai.com/api/docs/guides/your-data). У SciSense сирі аудіо/фото/розшифровка очищаються після закриття чернетки. Виняток: після невизначеного збереження команда з нормалізованими позиціями без сирих медіа лишається у пам’яті відкритої сторінки для тотожного повтору. Вона очищається після підтвердження, визначеної відмови, перезавантаження, зміни дня/профілю або виходу. У журнал потрапляють тільки коди результатів, часи, моделі, лічильники й витрати.

## Телефон: стан і роботи до ввімкнення

Погоджений напрям лишається локальним HTTPS у спільній Wi-Fi мережі з Mac. Публічний tunnel, production Firebase та нова платна Cloudflare інфраструктура не потрібні для цієї лабораторії. Пропозиція API не означає, що телефонний URL уже працює.

У межах погодженого блоку 3 підготовлено [локальний HTTPS-канал](PHONE-LAB.md): окрема збірка з точним origin, loopback demo Auth/Firestore, одноразове сполучення, test-only JWT adapter без послаблення production RS256. Проксі перевіряє UID/project і всі носії токена. TLS-ключ проходить через pipe до Keychain. Адаптер постійного SQLite-бюджету перевірено на restart, пошкодженому файлі й зміні стелі.

Автоматизований браузерний сценарій із підставними моделями пройшов голос → фото → 106 ккал → збереження → reload. Це не реальний API та не встановлена довіра на телефоні. CLI поки приймає тільки live=false, ключі провайдерів не читає.

До першого платного виклику залишаються: погодження бюджету $5, підтверджена Console organization/баланс/строк кредиту, реалізація локального Whisper, затверджена конфігурація live-бюджету та явна TLS-довіра на телефоні. Проєктний ключ уже збережений і автентифікує читальний Models API. G04 залишається гейтом приватного пілоту й production. Нова оплата, публікація і злиття PR не виконані.

## Що ще погоджує Юрій

Модель Sonnet і окремий ключ у Default вже обрані. На погодженні: локальний Whisper + Sonnet 5.5, наведені 10 тестових сценаріїв і передавання даних, стеля $5 на весь прогін лише з Claude-кредитів. Після дозволу довести локальний аудіоадаптер і live binding; перевірка особистого кредиту й TLS-довіра лишаються окремими фактичними передумовами.

[pilot-proposal.json](../workers/meal-parser/pilot-proposal.json) є несекретною пропозицією, не конфігом розгортання. Статус pending, LIVE_ENABLED=false, дата погодження витрат порожня. Models API 200 не підтверджує баланс і не дозволяє inference.

## Критерії локальної підготовки Sonnet

- S01: запит до Sonnet використовує підтримуваний JSON outputs контракт, точну модель, без forced tool choice і без fallback.
- S02: refusal, обрізана/підмінена відповідь, невалідні поживні значення відхиляються; існуючий формат чернетки етикетки зберігається.
- S03: фактична функція резерву дає $3.039200 для набору; непогоджені ціни/вимкнений live не допускають генерації.
- S04: proposal/docs містять Sonnet, Default, $5 pending; секретів немає, код транскрипції та ліміти не послаблені.
- S05: `npm test` і `npm run check` у workers/meal-parser проходять без inference; реальний голос/фото на API ще не заявлені готовими.
