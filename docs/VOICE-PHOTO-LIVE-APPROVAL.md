# Реальні API й телефон: пакет на погодження

Дата: 2026-10-20. Статус: підготовлено для рішення Юрія, витрати не дозволені. Це уточнення кроку 4 [погодженого плану](superpowers/plans/2026-10-20-voice-photo.md), а не повторне погодження голосу/фото. Goal `objective_e45aa8ac1aa3`, G05/G07/G08/G11 залишаються pending.

## Кредити й акаунт

Вимога Юрія: використати щомісячні API-кредити його підписки. Готуємо варіант для Claude Max; назву «Cloud Code» ще уточнюємо. Офіційно Max 5x має $100, Max 20x має $200 на місяць. Кредити отримує одна прив’язана Console organization, вони діють у прямому Claude API, не оплачують OpenAI. Баланс спільний для ключів організації, невикористане не переноситься. Це підтвердження програми, не особистого залишку Юрія. [Умови](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans).

Перед запуском потрібні назва/ID погодженої організації, видимий залишок та строк кредиту. В [Claude Billing](https://claude.ai/settings/billing), секція `API credits`, перевірити `Link organization`; не прив’язувати довільну нову організацію, бо самостійна зміна прив’язки недоступна. Підтверджений баланс видно в [Console Billing](https://platform.claude.com/settings/billing). У вибраній організації потрібен окремий workspace SciSense і його ключ, а не ключ чужого продукту. Наразі `find.py scisense` повернув found=0; значень секретів не читали. OAuth Claude Code не підставляється замість API key.

| ------------------------------------- | ----------------------------------- | ------------------------------------- | --------------------------------------- |

| Текст + фото → продукти, порції й БЖВ | `claude-haiku-5-5`                  | $0.10 / $0.50, вхід до 100000 токенів | Кредити прив’язаної Claude organization |

Тарифи: [OpenAI](https://developers.openai.com/api/docs/pricing), [Haiku](https://platform.claude.com/docs/en/models/haiku-5-5/overview). Це ціни API в USD, без можливих податків під час придбання балансу. У цьому прогоні придбання балансу не передбачено. Haiku приймає текст/зображення; аудіо цим API-контрактом не приймається. Його forced tool call сумісний з поточним `food_record`, без thinking block. Sonnet 5.5 не є простою заміною: forced tool use там відхиляється. Тому автоматичного переходу на дорожчу модель немає. [Haiku migration](https://platform.claude.com/docs/en/models/haiku-5-5/migration-guide), [Sonnet](https://platform.claude.com/docs/en/models/sonnet-5-5/overview).

Початковий прогін: 10 голосових повідомлень до 90 секунд, серед них 5 із двома фото. UI аналізує кожне додане фото окремо: разом 10 транскрипцій + 10 первинних розборів + 5 розборів з одним фото + 5 із двома = 30 API-викликів. Відмова або повтор витрачає ліміт; не запускаємо автоматичні повтори й не приховуємо невдалі спроби.

Консервативний резерв, обчислений на чинному `reservation()`:

| Тип виклику     | Кількість | Резерв одного |         Разом |
| --------------- | --------: | ------------: | ------------: |
| Транскрипція    |        10 |     $0.030000 |     $0.300000 |
| Текст, без фото |        10 |     $0.006848 |     $0.068480 |
| Одне фото       |         5 |     $0.007848 |     $0.039240 |
| Два фото        |         5 |     $0.008848 |     $0.044240 |
| Сума            |        30 |               | **$0.451960** |

Для аудіо резервуємо всі 16000 вхідних і 2000 вихідних токенів. Для аналізу: до 32000 UTF-8 bytes тексту, 16000 токенів запасу інструкцій/схеми, 10000 на кожне фото та max_tokens=4096. У Haiku це не перевищує поріг 100000; документація vision обмежує одне зображення 4784 visual tokens, запас 10000 більший. [Межі аудіо](https://developers.openai.com/api/docs/models/gpt-4o-mini-transcribe), [vision](https://platform.claude.com/docs/en/build-with-claude/vision).

Пропонуємо абсолютний сукупний ліміт **$1 API-витрат** на весь цей запуск, не на день. Сума $0.451960 є резервом базового набору, не прогнозом рахунку. З неї $0.151960 резервується для Claude-кредитів, $0.30 для OpenAI. Якщо витрачати запас лише на звук, він теж буде поза Claude-кредитами; окремої провайдерної стелі в поточному коді немає, сукупна лишається $1. Орієнтир фактичного рахунку $0.05–0.10 лише для коротких відповідей/записів, його треба виміряти. Для B пропонуємо $0.25 тільки Claude-кредитів; це потребує окремого локального адаптера й перевірки лімітера, поточний Worker B не вмикає.

Budget SQLite зберігає повний резерв і після помилки, 6 викликів за ковзну хвилину, 30 за UTC-добу, 2 одночасні на UID. У базовому наборі вже 30 викликів: при помилках/повторах частину сценаріїв переносимо, не збільшуємо квоту. Один постійний файл бюджету на весь запуск; перезапуск або зміна UTC-дня не скидає суму. Втрата файла означає зупинку до звірки витрат, а не новий порожній бюджет. Нова сесія/підвищення ліміту потребує нового дозволу. Фіксуємо доступний кредит до запуску та вимикаємо запуск, якщо його недостатньо; спільний баланс інших продуктів не вважаємо гарантованим резервом SciSense.

Перед першим платним запитом треба повторно перевірити доступність точних ID через Models API і поточні тарифи. `gpt-4o-mini-transcribe` вимикається 26.02.2027; A пропонується для цього тесту зараз, не як довгострокове рішення. Міграцію на `gpt-transcribe` перевіряємо окремо перед релізом. [Офіційне повідомлення](https://developers.openai.com/api/docs/deprecations).

## Матеріали й передавання

Цей голос передається OpenAI у варіанті A; текст і фото йдуть до Anthropic. Результат записується лише в ізольований demo Firestore, не у справжній щоденник.

У сценаріях 6–10 спершу фото назви, потім таблиці. Першу відповідь після назви не видаємо за точну етикетку. Збереження позитивних сценаріїв: одна «Додати», перевірка правильного дня та повторне читання після reload, без дублів. 8 і 10 очікувано зупиняються на уточненні. Ця перевірка API не підміняє 7-денний G09-пілот і його знаменник усіх спроб.

Anthropic API: стандартне видалення input/output протягом 30 днів, з винятками політики/закону; без навчання на цих даних за замовчуванням. Files API і добровільне передавання для навчання не використовуємо. [Зберігання](https://privacy.claude.com/en/articles/7996866-how-long-do-you-store-my-organization-s-data), [навчання](https://privacy.claude.com/en/articles/7996868-is-my-data-used-for-model-training).

Для конкретного OpenAI `/v1/audio/transcriptions` таблиця документації вказує відсутність зберігання в abuse monitoring/application state і відсутність навчання. Це не переноситься автоматично на інші OpenAI endpoints. [Політика endpoint](https://developers.openai.com/api/docs/guides/your-data). У SciSense сирі аудіо/фото/розшифровка очищаються після закриття чернетки. Виняток: після невизначеного збереження команда з нормалізованими позиціями без сирих медіа лишається у пам’яті відкритої сторінки для тотожного повтору. Вона очищається після підтвердження, визначеної відмови, перезавантаження, зміни дня/профілю або виходу. У журнал потрапляють тільки коди результатів, часи, моделі, лічильники й витрати.

## Телефон: стан і роботи до ввімкнення

Погоджений напрям лишається локальним HTTPS у спільній Wi-Fi мережі з Mac. Публічний tunnel, production Firebase та нова платна Cloudflare інфраструктура не потрібні для цієї лабораторії. Пропозиція API не означає, що телефонний URL уже працює.

Потрібно завершити в межах блоку 3 (повний перелік):

1. Окремий HTTPS-вхід для статичної lab-збірки, Auth/Firestore emulator і локального Worker. Точні hostname/origin, demo-scisense, прив’язка лише до потрібного LAN-інтерфейсу; сервери емуляторів тільки loopback. TLS-довіру на телефоні встановлює Юрій; агент її не імітує. Сертифікат має містити фактичну адресу, не приклад URL.
2. Окремий test-only Auth adapter, доступний лише через захищений lab-вхід. Він перевіряє demo issuer/audience/expiry, зареєстрованого test UID і локальну авторизовану сесію; сама перевірка unsigned JWT або Origin недостатня. Production RS256 handler не змінюємо. Провайдерний ключ ніколи не потрапляє в браузер.
3. Browser SDK підключити до HTTPS proxy без mixed content. Поточний `connectFirestoreEmulator` для localhost/LAN задає незашифроване з’єднання, а `src/firebase.js` відхиляє LAN hostname; обидва випадки перевірити на окремій lab-конфігурації без fallback на production. Не можна просто вписати LAN URL замість localhost.
4. З’єднати постійний локальний SQLite бюджет із реальним адаптером. До погодження live=false, без ключів. Після нього ключі з Keychain передавати тільки в пам’ять процесу, не `.dev.vars`, argv, Git або логи. Ліміт й ідентичність моделі прив’язані до погодження.
5. Перевірити відмови непарній сесії/чужому UID, обхід прямого API, неправильний origin/project/model, вичерпання/перезапуск бюджету та аварійне закриття. Власний headless browser: ізоляція Firebase, MIME/сховище/HTTPS, cleanup. Потім фізичний телефон: довірений сертифікат, справжні мікрофон/камера, читання збереженого дня.

Цей канал ще не реалізований; сьогоднішній пакет містить перевірені кандидати/бюджет/матеріали й порядок підключення. G04 залишається гейтом для приватного пілоту та production. Публікація, злиття PR і нова API-оплата не виконані.
