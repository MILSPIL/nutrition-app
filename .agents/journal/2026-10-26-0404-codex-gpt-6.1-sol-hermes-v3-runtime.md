## Результат

Додав окремі V3 runtime/activation і вимкнений шаблон, main обирає їх лише для version3. Groq Free використовує лічильник тільки нульової вартості. Anthropic і старий валютний ledger не відкриваються. Квитанція зв’язує власника підключення, профілі, dataProfiles, ролі, реліз, policyHash і гейти. Справжній UID дружини ще невідомий, не підставлений. Два HTTP слоти не змінюють model FIFO: один активний, чотири очікують. B3: 8 turn, 24 POST, до 3 POST на turn, 45 секунд після черги.

Uploads мають бути на actual tmpfs. Лише порожні тимчасові каталоги дозволено відтворювати після reboot. Idle sweeper прибирає orphan/partial файли з monotonic bound 295+5 секунд. Native retained history він не обходить. Fault latch блокує runtime і зупиняє watchdog до очікування Native close; PID1 прибирає RuntimeDirectory. Startup failure теж закриває helper. Firebase ключі для UID виводяться завчасно, тому caller може стерти bootstrap key до першого lazy vault access.
