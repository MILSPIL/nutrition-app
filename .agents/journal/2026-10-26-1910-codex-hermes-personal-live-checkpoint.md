- Legacy native chat не приймав remote SCISENSE principal. Одноразова native local adoption має явно прив'язувати authenticated_subject того самого remote користувача і мінімальні toolsets; звичайний GUI default додав би сторонні інструменти. Квитанція підтвердила незмінні ID/історію/контекст та live resume.
- OpenSSH9.6 вимикає й StreamLocal, коли AllowTcpForwarding=no. Для окремого користувача застосовано local із подвійною точною PermitOpen/authorized-key ACL тільки власного UDS. Реальна TCP/session відмова підтверджена; чужий socket негативним запитом ще не перевірявся.
- macOS security повертає multiline PEM як hex; перед ssh-add потрібне декодування. UserKnownHostsFile зі пробілами потребує внутрішнього quoting; -F/dev/null прибирає успадкований ControlMaster. Приватний ключ на диск не записувався.
