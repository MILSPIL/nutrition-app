## Виявлена причина виводу

Зафіксований Whisper із `-f - -otxt` використовує `ofstream('/dev/stdout')` без перевірки помилки. Linux Node pipe відтворив exit 0 без тексту. Native callback із `-of scisense-stdout` без прапорців експорту або `-ls` повертає текст напряму й не створює файлів. Це окреме виправлення, яке не доводить причину таймаутів.

Context7 був недоступний через вичерпану квоту. Використано первинний CLI-код d1be6fde та офіційну документацію Node 24.11.1 щодо stdio.
