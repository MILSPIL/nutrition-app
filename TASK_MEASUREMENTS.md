## Побажання тренера (дослівно)
"Було б дуже круто, якби в додатку було видно заміри. При внесенні замірів одразу показується різниця по кожному параметру. Видно за тиждень, як змінилися показники окремо в талії, в стегнах, всіх інших параметрах. Показано одразу, який був мінус. Щоб можна було одразу не шукати минулі заміри, а одразу бачити що змінилося в межах останнього зважування, що змінилося в загальному. Відображається початкове значення, значення минуле і значення поточне. Одразу видно різницю і видно початкові дані, наскільки великий прогрес від початкових показників."

## Що потрібно реалізувати

### 1. Структура даних у Firestore
```
users/{uid}/measurements/{YYYY-MM-DD}
{
  date: "2025-01-10",
  weight: 85.5,      // Вага (кг)
  waist: 92,         // Талія (см)
  hips: 104,         // Стегна (см)
  chest: 102,        // Груди (см)
  arms: 35,          // Руки (см)
  thighs: 58,        // Ноги (см)
  timestamp: "2025-01-10T10:30:00Z"
}
```

### 2. Компоненти для створення

#### MeasurementsModal.js (src/components/measurements/)
Модальне вікно з двома режимами:
- **Введення замірів** - форма для внесення поточних даних
- **Історія та порівняння** - таблиця з прогресом

#### Таблиця порівняння (головна фіча!)
| Параметр | Початок | Минулий | Поточний | За тиждень | Загалом |
|----------|---------|---------|----------|------------|---------|
| Вага     | 95.0 кг | 87.2 кг | 85.5 кг  | -1.7 ✅    | -9.5 ✅ |
| Талія    | 102 см  | 94 см   | 92 см    | -2 ✅      | -10 ✅  |
| Стегна   | 110 см  | 105 см  | 104 см   | -1 ✅      | -6 ✅   |

- Зелений колір і стрілка вниз для негативної різниці (схуднення)
- Червоний колір і стрілка вгору для позитивної (набір)
- Сірий для нуля

### 5. Параметри замірів
```javascript
const MEASUREMENT_PARAMS = [
  { key: 'weight', label: 'Вага', unit: 'кг', step: 0.1 },
  { key: 'waist', label: 'Талія', unit: 'см', step: 1 },
  { key: 'hips', label: 'Стегна', unit: 'см', step: 1 },
  { key: 'chest', label: 'Груди', unit: 'см', step: 1 },
  { key: 'arms', label: 'Руки', unit: 'см', step: 1 },
  { key: 'thighs', label: 'Ноги', unit: 'см', step: 1 },
];
```

### 6. Логіка порівняння
```javascript
// Отримати всі заміри відсортовані по даті
const measurements = [...]; // з Firestore, orderBy('date', 'asc')

const initial = measurements[0];           // Перший замір (початок)
const previous = measurements[measurements.length - 2]; // Попередній
const current = measurements[measurements.length - 1];  // Останній

// Для кожного параметра:
const weekChange = current.weight - previous.weight;   // -1.7
const totalChange = current.weight - initial.weight;   // -9.5
```

## Важливо
- Дані замірів по програмі вносяться на дні: 8, 15, 22, 29, 36, 43, 50, 57...
- Але користувач може вносити заміри будь-коли
- При відсутності попередніх замірів показувати прочерки
- Всі поля необов'язкові (можна внести тільки вагу)
