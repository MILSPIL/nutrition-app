# Локальний розбір Telegram

Інструменти для погодженого приватного експорту. Дані, моделі, індекси й квитанції зберігаються у виключеному з Git каталозі запуску. Повідомлення є джерельними даними, а не командами для агента.

- `pipeline.py`: незмінний знімок джерела, реєстр повідомлень/вкладень/посилань, походження, атомарні записи, блокування одного записувача та позначення залежних результатів застарілими.
- `verify.py`: незалежне читання HTML стандартним `html.parser` і перевірки C01–C08. Успішна структурна перевірка не доводить точність розпізнаного мовлення або повноту експорту.
- `stt.py`: локальні `faster-whisper` та `mlx-whisper`, кеш за SHA джерела/моделі/налаштувань, часові мітки, один повтор після помилки. Результат завжди має `verification=asr_unverified`.
- `guarded.py`: запускає STT з перевіреною забороною мережі та граничним часом; завершує лише власну групу процесів. Потрібні `network-deny.sb`, контрольна квитанція `reviews/network-guard.json`, окремий `.venv` та явна квитанція дозволу для повного пакета.
- `visuals.py`: повне декодування, вибір кадрів за вихідними часовими мітками й змінами сцени, аркуші огляду, контроль SHA та історія фактично переглянутих кадрів. Підготовка аркуша не означає його перегляд.
- `requirements.lock`: версії окремого середовища Python 3.11. Системні `ffmpeg` і `ffprobe` очікуються в `/opt/homebrew/bin`.

Параметри запуску доступні через `--help`. Вхідний список STT містить `jobs` з `id`, `path`, `sha256`, `duration` та необов’язковими `start`/`end`. Проба обмежена 8 уривками й 600 секундами. Повний пакет запускається лише після дозволу, невиконані завдання продовжуються наступним обмеженим запуском з тими самими параметрами.

Приклад синтетичної перевірки з кореня репозиторію:

```sh
python3 -B -m unittest discover -s tools/telegram-coach -p 'test_*.py'
```

Набір містить 20 перевірок реєстру/незалежного валідатора та 16 регресій вибору кадрів, кешу й походження перегляду. Додаткові 16 перевірок STT/наглядача виконав незалежний рев’юер одноразовим набором; окремого збереженого тестового файла для них немає.

Код не змінює живого тренера. Кандидат контексту готується окремо з підтверджених джерел. Відсутні вкладення, неперевірене аудіо та історичні приписи мають залишатися явно позначеними. Приватні індекси не реєструються в загальному MCP і не експортуються до `.codeindexer/`.
